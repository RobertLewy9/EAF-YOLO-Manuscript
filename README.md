# Gains Within Seed Noise

**A Five-Seed Audit of a Lightweight Module for Underwater Marine Debris Detection, with Same-Protocol Ports of Four Published Alternatives**

Authors: Jiangfan Feng, Changqing Luo

## Contents

- `Gains_Within_Seed_Noise.pdf` - manuscript prepared for journal submission.

## Scope

This repository is limited to the manuscript and its basic publication metadata.
It does **not** contain model source code, architecture definitions, training
configurations, checkpoints, logs, or per-run experiment records.

The SeaClear and TrashCan-1.0 datasets are public and remain subject to their
original terms of use. No dataset copy is redistributed here.
